iostreams:
==========
Stream: 
------
Sequence of data that flows between a source and destination. 

Input Stream: 
-------------
- Used to read the data
eg: reading from keyboard or file  or network

Output Stream:
-------------- 
- Used to write data 
- Eg: writing to a file, console. 

try with resources
=================

try with resources allows you to declare resources like files,streams, database connections
inside the try statement, so that they are automatically closed after use. 

- It eliminates the use of finally block to close the resources
- It prevents the resource leaks
- try with resources works with any object that implements AutoCloseable interface.

Syntax:

try(FileWriter  writer = new FileWriter("writer.txt")){

}catch(Exception e){
e.printStackTrace();

}

AutoCloseable interface: 
------------------------
AutoCloseable interface enables automatic resource management.
- It is in java.lang
- contains a single method close()

Any class that implements AutoCloseable can be  used in try-with-resources

eg: FileReader,FileWriter,BufferedReader, BufferedWriter, Connection etc.
-When you use try-with-resources,JVM will automatically call close()
- Even if exception occurs, resources are still  safely closed.
