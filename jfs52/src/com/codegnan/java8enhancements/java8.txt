Java 8 introduced Functional interfaces
 - An interface with Single abstract method
 - Multiple static and default methods.
 - Functional interface can be implemented
    using Lambda expressions, Method references.
    
Java 8 -
 introduces concrete methods in interaces - static methods and default methods
 These static and default need not be overridden in implementation classes. 
 
 default method:
 --------------
 - It is public by default
 - It is created by using a keyword 'default'
   eg:  
   default void myDefaultMethod() {
		System.out.println("Default Method in interface");	
	}
  - default methods need not be overridden in the implementation class. 
  - We can use the default method implementation in the interface directly. 
  
  static Method: 
  -------------
  - A method which is declared using static keyword. 
  - It can be accessed in implementation classes using Interface name. 
    eg. MyInterface.myStaticMethod();
    
    eg:
    public static void myStaticMethod() {
		System.out.println("My static method");
	}
	
	
Lambda Expression: 
==================
Lambda expressions are introduced in java 8
Lambda expressions are the implementation of Functional Interface methods. 
Lambda expression can be used only with a Functional interface. 

Syntax: 

() -> Implementation; 

() denotes the arguments of the function
-> denotes a lambda expression
implementation is the body of the method. 


 Predicate
 ----------
 - Predicate functional interface is present in 
     java.util.function
 - It has a Single abstract method which returns a boolean value:
    boolean test(T t);
  - test() method has a single argument and returns a boolean
  
  - this method is implemented to test a particular condition
 
 
 BiPredicate: 
 -----------
 - It is in java.util.function
 - Accepts 2 arguments of types T and U
 - syntax: boolean test(T t, U u);
 - It returns boolean result based on the given logic. 
 
 
 Function: 
 ========
 - present in java.uti.function 
 - it has a Single abstract method: 
   R apply(T t);
   where 
   R can be any Return type
   T  can be an  argument of any type. 
 
 
 Function Chaining:
 ==================
 Function chaining combines multiple Functions into a sequence. 
 - The output of one function becomes the input of the next function
 
 
 .andThen() method: 
 ------------------
 - andThen() applies first function, then applies the next function on the result. 
 Function<T,R> combinedFunction= firstFunction.andThen(secondFunction);
 
 .compose() method: 
 ------------------
 - compose() method applies the second Function first, then applies first function
   on the result. 
   
    Function<T,R> combinedFunction= firstFunction.compose(secondFunction);
