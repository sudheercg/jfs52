List Interface: 
---------------
List interface extends Collection interface.
It is in java.util package
Implementation classes of  List: 
AllList implementations allow duplicate elements. 

- Vector (Legacy class)
- Stack

ArrayList
LinkedList



java.util.ArrayList implements List
- ArrayList internally maihtains an Array
- It stores the objects in contagious memory location. 
- It is dynamic in nature, its size automatically increases
   once the threshold level is reached. 
- Default capacity of an arrayList is 10.
- When 10 elements are filled, a New arrayList with double the capacity
   of the original array is created. 
  And all the elements from old array is shifted to new array. 
  Old array is removed. 
- ArrayList supports heterogenous types by default, because it is a generic
   class. 
- You can make an ArrayList typesafe by specifying the type in angular brace. 
- ArrayList allows duplicates.
- ArrayList allows nulls. 
- Elements in the ArrayList can be accessed with an index. eg. get(1)


LinkedList: 
- Internlly maintains a Doubly Linked List
- It is best suited for Insertions and deletion operations

ArrayList is best suited for Search operations. 
ArrayList is not suitable when you have huge number of insertions and deletions
 as there is shifting of elements when an element is added or deleted. 

Vector : 
========
- Vector implements List interface
- It is like ArrayList. 
- Difference between ArrayList and Vector is that Vector is synchronized
  i.e it is thread-safe by default
- It grows automatically when elements are added
- It mains insertion order
- allows duplicates
- allows null values. 


Vector internally implements synchronization.
But ArrayList will not use synchronization by default
- To  synchronize an ArrayList :
   List list= Collections.synchronzedList(new ArrayList());


Stack: 
=====
Stack extends Vector class.
Since it extends Vector class, it is also synchronized. 
Stack uses LIFO(Last in first out) data structure
The last element added is the first to be removed.

IMportant methods: 
------------------
push(element): add element at the top of the stack
pop(): remove top  element
peek(): view top element
empty(): checks whether stack is empt
search(): postion from top.
